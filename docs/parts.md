# Parts list

All files are STEP (AP214) exports from Fusion 360. The hitter and seeker files are the
mechanisms used in each round of the game: as hitter we throw balls at the other team's
robots and as seeker we break the lagori pile and build it back up.

## R1

| File | What it is |
|------|------------|
| `cad/r1/r1_body.step` | Full R1 assembly |
| `cad/r1/parts/hitter_ball_receiving.step` | Ball receiving and hitting setup (hitter round) |
| `cad/r1/parts/seeker_lagori_breaking.step` | Pipe shooter used to break the lagori pile (seeker round) |
| `cad/r1/parts/rotating_table_mechanism.step` | Rotating table with its gear |
| `cad/r1/parts/rotating_table_perforated.step` | Perforated plate of the rotating table |
| `cad/r1/parts/hydraulics_perforated.step` | Perforated plate for the lifting stage |
| `cad/r1/parts/linear_actuator.step` | Linear actuator |
| `cad/r1/parts/linear_actuator_piston.step` | Linear actuator with piston |
| `cad/r1/parts/mecanum_wheel.step` | Mecanum wheel with 12 V DC motor, coupler and clamp |
| `cad/r1/parts/caster_wheel.step` | Caster wheel |

## R2

| File | What it is |
|------|------------|
| `cad/r2/r2_body.step` | Full R2 assembly |
| `cad/r2/parts/hitter_ball_picking.step` | Lifting platform that picks the balls and passes them to R1 (hitter round) |
| `cad/r2/parts/seeker_lagori_piling.step` | Lifting platform with suction cups that piles the lagori discs (seeker round) |
| `cad/r2/parts/omni_wheel.step` | Omni wheel with its motor mount |
| `cad/r2/parts/head_plate.step` | Top plate of the frame |
